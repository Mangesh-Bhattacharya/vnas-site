Roadmap

Ordered by dependency and risk: security foundations first, then reach, then scale.
✅ = implemented and tested in this repository · 🧩 = scaffolded · ⬜ = planned.

Phase 1 — Secure MVP (foundation everything else depends on)

Item Depends on
✅ Key hierarchy, Argon2id, AEAD with AAD binding, sealed-box sharing, signed manifests (@vnas/core) —
✅ Zero-knowledge sign-up, login, recovery key, password change crypto
✅ TOTP MFA with replay protection and recovery codes auth
✅ Sessions, device enrolment and revocation, rate limits, lockout auth
✅ Spaces, RBAC (global + per-space), invites, quotas, groups auth
✅ Items: files (chunked, versioned, deduped, resumable), folders, notes, vault entries, records, trash spaces
✅ Change feed + offline outbox sync + conflict policies items
✅ E2EE share links; key rotation on unshare items
✅ Intake links: anonymous, zero-knowledge external submission (forms + documents) into a drive/records space, with per-item AI exclusion until a human promotes the submission items
✅ Signed, hash-chained audit log; health, metrics, webhook alerts —
✅ Web client / PWA with offline unlock core
✅ Docker/Compose/Caddy, systemd, K8s, restic backups, CI security scanning, signed releases server
Exit criteria External crypto review of crypto.ts + auth flows; restore drill passes

Phase 2 — Every device (≈ 6–8 weeks)

Item
🧩 Desktop (Tauri): keychain unlock, signed auto-update. Next: first build, tray icon, folder sync to the local filesystem (watcher → outbox)
🧩 Mobile (Expo): biometric unlock, SQLite cache, background sync. Next: first device build, verify react-native-libsodium API coverage, camera upload, share-sheet intake, OS autofill provider for the vault
⬜ WebAuthn / passkeys (server: go-webauthn; also PRF-based unlock)
⬜ Server-sent events for instant sync; conflict review / diff UI
⬜ Full-text search: SQLite FTS5 on desktop/mobile, MiniSearch on web
⬜ Off-box audit shipping (syslog / WORM S3)
⬜ Browser extension for vault autofill

Phase 3 — Assurance (≈ 6 weeks)

Item
⬜ OPAQUE aPAKE login (removes the offline-guess oracle on server compromise)
⬜ Key transparency / TOFU pinning of contacts' public keys with change warnings
⬜ Chunk-size padding to reduce metadata leakage
⬜ Lazy re-encryption job after member removal (re-wrap item keys to the new epoch)
⬜ Hardware keys for unlock (YubiKey HMAC/PRF, TPM-sealed key on Windows/Linux)
⬜ Reproducible builds; third-party penetration test; bug bounty

Phase 4 — Scale and integrations

Item
🧩 AI agent: local RAG, redaction, coaching (✅). Next: persistent encrypted vector index (sqlite-vec), PDF/Office/OCR extractors, scheduled insight digests
⬜ S3-compatible blob backend (MinIO/Garage/B2); PostgreSQL store for multi-node HA
⬜ WebDAV gateway on the client side (mount the decrypted drive locally)
⬜ Photo timeline, thumbnails generated client-side
⬜ Import from Google Drive / OneDrive / Bitwarden / KeePass exports
⬜ Structured records UI (schema builder, table views)

Milestones

  1. M1 (done here): a tested core, server and web client, deployable via Compose.
  2. M2: signed desktop builds for all three OSes and Android APK; WebAuthn.
  3. M3: external security review complete; v1.0 release.
  4. M4: iOS App Store / TestFlight, F-Droid, S3 backend.
