vNAS gives you what Google Drive and OneDrive do, on hardware you own: files with version history, notes, a password manager and structured records, all synced across Windows, macOS, Linux, iOS and Android. Everything is encrypted on your device before it leaves, so even the person running the server can't read it. A private AI assistant runs alongside on a local model.

Features

Everything in one place

The things you'd otherwise spread across a cloud drive, a notes app and a password manager, in one encrypted space you control.

Drive

Drag in files of any size. Uploads resume after a dropped connection, unchanged parts are never re-sent, and every save is kept as a version you can roll back to.

versioningdeduptrash

Notes

Markdown notes with tags that save as you type. If two devices edit the same note offline, you keep both versions instead of losing one.

markdowntagssearch

Passwords

A zero-knowledge vault with a password generator and a security check that flags weak and reused passwords. Copied passwords clear from the clipboard after 30 seconds.

generatorhealth checkshared vaults

Records

Structured entries for the things that don't fit in a file: warranties, subscriptions, medical history, home inventory. Encrypted like everything else. The table editor is on the roadmap.

custom fieldsEditor coming

Sharing & roles

Admin, user, read-only and guest roles, groups, and per-space editor or viewer access. Share a single file with an expiring link that carries its own key.

RBACgroupslinks

Offline-first sync

Everything you've opened works without a connection. Changes queue up and sync when you're back, with clear rules for conflicts so nothing silently disappears.

Security

Private by construction, not by promise

Your password never leaves your device. It unlocks a chain of keys that only your devices hold, so a stolen server, a nosy admin or a subpoena gets ciphertext and nothing else.

How your data is locked

  1. 01
    Your passwordStretched on your device with Argon2id (128 MiB, 3 passes).
  2. 02
    Account keyUnwrapped locally. The server only stores it encrypted.
  3. 03
    Space keysOne per drive or shared vault, sealed to each member's public key.
  4. 04
    Item keysEvery file, note and password has its own key, sealed with XChaCha20-Poly1305.

What the server actually stores

Ciphertext only
item 9b2f…c41e kind=note rev=17 payload 0x01·4be1d0…f29a73c0e1… (encrypted) key 0x01·a07c55…3e18b9d2… (wrapped) audit #36 note.update sha256=7f0e… sig=ed25519 ✓
  • Two-step verification with backup codes, and a printed recovery key
  • Tamper-evident audit log: every entry is hash-chained and signed
  • Revoke a lost device from anywhere; remove a member and the keys rotate
  • Signed releases, SBOMs and dependency scanning on every build

The trade-off: no one can reset a forgotten password for you. Your recovery key is the only way back in, so keep it safe.

AI assistant

An assistant that only sees what you share

The assistant is its own vNAS account. You share specific spaces with it, the same way you would with a person, and unsharing takes its access away. It runs 24/7 on a local model, so by default nothing leaves your network.

  • Ask questions across your notes and documents, with sources cited
  • Summaries, tag and folder suggestions, and plain-language security advice
  • Runs on Ollama with free models, from a Raspberry Pi to a GPU box
  • Cloud models are off by default. If you turn them on, emails, card numbers and keys are masked first
  • Never reads your passwords, even if you share the vault
  • Can't edit, move, share or delete anything

Ready

  • Metrics, health checks and alerts to ntfy or any webhook

Roadmap

The path so far

Security foundations first, then every device, then independent review, then scale.

  1. Phase 1Done

    Secure core

    Encryption, sign-in with two-step verification, files, notes, passwords, sharing, offline sync, the audit log, the web app and Docker deployment. Covered by end-to-end tests against a real server.

  2. Phase 2In progress

    Every device

    Signed desktop apps for Windows, macOS and Linux, Android and iOS apps, passkeys, instant sync and full-text search.

  3. Phase 3Next

    Independent assurance

    External crypto review and penetration test, a stronger login protocol, verified contact keys and reproducible builds. v1.0 ships after this.

  4. Phase 4Later

    Scale and integrations

    S3 and PostgreSQL backends, a mountable drive, a photo timeline, and imports from Google Drive, OneDrive, Bitwarden and KeePass.
